## movieclaw v0.2.0

首个支持应用内更新的版本。

### 新增

- **应用内更新**：设置 → 应用 → 检查更新，一键升级免拉镜像；支持一键回退、NER 识别模型独立更新、更新清单 Ed25519 签名校验
- **「应用」设置分区**：外部访问地址（设置后 AI 助手回复与通知可携带指向本应用的页面链接，输入框内一键采用当前地址）；应用重启（Docker 部署秒级恢复、前端不中断）
- **微信绑定**：把 AI 助手接入你的微信，扫码即用（需先配置 AI 模型）
- **AI 助手**：上下文自动压缩不再爆窗、影音助理身份提示词重塑、回复可携带指向本应用的准确页面链接
- **媒体库**：strm 网盘占位文件同权入库识别；待识别条目无匹配时给出补录引导；字母索引条重做（吸附居中 + 滑动选中）
- **搜索**：新增「媒体库」搜索垂直，搜索范围为「影视 | 资源 | 媒体库」

### 说明

- 本版本起，后续升级都可在「设置 → 应用」内一键完成，无需重拉 Docker 镜像
- 运行时依赖无变化（runtime=1），现有镜像可直接应用内更新到本版本
