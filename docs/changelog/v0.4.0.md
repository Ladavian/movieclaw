## movieclaw v0.4.0

订阅可干预、消息可推送、站点可自定义，外加一轮全面的发布后质量修复。

### ⚠️ 需要更新 Docker 镜像（runtime 1 → 2）

本版本新增 Telegram/Discord 推送通道，显式引入了 `websockets` 运行时依赖。
旧镜像用户在「设置 → 应用」会看到「需升级 Docker 镜像」提示，请先
`docker pull` 新镜像再更新应用。

### 新增

- **Telegram / Discord 推送通道**：与微信通道同级的消息推送与对话入口，
  「设置 → 消息推送」内填 bot 凭据、6 位配对码完成绑定；下载完成、订阅
  动态等通知统一推送到已绑定的通道
- **订阅手动干预三件套**：订阅详情页支持「立即搜索」（不等下轮调度）、
  「调整订阅」（改季选择/追新/规则组/入库库，含改回「按默认库路由」）、
  「手动选种」（绕过规则组直接投递指定种子，规则太严时的逃生口）
- **订阅实时下载进度**：详情页展示在途种子的速度 / ETA / 进度条（约 5 秒
  刷新），qBittorrent 与 Transmission 状态语义已对齐
- **监听导入台账与人工拍板**：导入结论分档（成功 / 待拍板 / 环境故障），
  「识别不出」不再算失败而是进清单等人工认领；新增「跳过存量」选项——
  开启监听时目录里已有的内容不再被重复整理；认领身份会持久化，环境故障
  自动重试时不会丢掉你的拍板
- **自定义站点配置**：新增 `data/site-configs/` 目录，放入 YAML 即可接入
  自建/未内置的 NexusPHP 站点，或覆盖内置站点配置（目录内附模板）；
  单个配置写错只跳过该站点，不影响其它站点与应用启动
- **新增 6 个内置站点**：观众、高清家园、朋友（keepfrds）、OurBits、
  猫站（PTer）、铂金家（PTHome）
- **媒体库整理增强**：条目内支持单文件删除（多版本洗版 / 删某集重下，
  最后一个文件自动升级为整条目删除）；库卡片支持自定义展示顺序（拖拽
  排序，首页同步生效）
- **发现页大改版**：豆瓣全量官方榜单 + TMDB 地区/平台/类型行，Netflix 式
  行序编排；榜单落地页通用化（Top250 之外任意榜单、高分电影均可进落地页
  浏览全量）；移动端点豆瓣外链直接拉起豆瓣 App
- **mclaw 独立 CLI**：模型操作产品的唯一命令行入口，命令树与后端 API
  同步生成，断网也可浏览 `--help` 全树
- **自定义 AI 接入点支持指定 User-Agent**：部分自建网关按 UA 过滤时可
  自行指定，留空即用 SDK 默认值（输入框会提示实际默认 UA）

### 改进

- **统一操作反馈层**：全站确认/输入弹窗与操作回执 Toast 换新（原生
  `confirm/alert` 全部退役），移动端不再被系统弹窗打断
- **全站性能**：液态玻璃改失效驱动重绘、海报墙增量渲染与视口外裁剪、
  轮询快照复用、搜索/Agent 流式合批——低配设备与长列表页面明显更顺
- **移动端体验**：语义字号体系对齐 iOS HIG、触控目标加大、Hero 轮播改
  横滑手势、Windows 下拉白底白字与全局滚动条样式修正
- **侧栏最近会话**：独立滚动、触底加载更多、行尾相对时间
- 下载进度轮询做了瘦身（不再拉整季包的文件清单），NAS 上开着详情页
  的磁盘/网络压力更小
- chdbits 站点换用可达域名 ptchdbits.co

### 修复

- **监听导入两类「无限期静默」死角**：下载完成瞬间被误判未完成后不再
  静默（自检 + 兜底闭环）；环境故障（FAILED）条目此前承诺「自动退避
  重试」但实际永不重试，现已兑现；CIFS/NFS 等不产生文件事件的挂载上
  带下载中标记的条目也不会再卡死
- **IM 通道稳定性**：Discord 遇网络层握手被拒（限频/代理故障）不再被
  误判为「凭据失效」而永久停摆；绑定成功/作废的回执消息不再因通道热
  切换竞态丢失；通知推送任务补强引用，杜绝偶发无声丢失；Telegram/微信
  收消息改为持续退避，持续故障时不再高频空转
- **侧栏最近会话分页竞态**：首屏与补页并发导致第 21–40 条会话永远不
  显示的问题已修复
- 调整订阅弹窗：入库库为空的老订阅不再「所见非所存」，且支持改回
  「按默认库路由」
- 豆瓣完整榜单尾页抓取失败时，半截结果只短缓存 5 分钟（原来要挂满
  6 小时）
- 手动选种在参数异常时回落服务端识别，不再报服务器错误
- 站点促销识别：朋友（keepfrds）中性种子（NL）不再被错误计上传
- 搜索与下载链路断点修补、下载目标弹窗记忆错乱修复、非 HTTPS 部署下
  新建会话报错修复

### 说明

- 数据库迁移向前兼容，应用内更新支持一键回退（跨版本回退由更新前的
  自动备份兜底）
- 本版本起合并门禁（pytest / ruff / 前端 lint+typecheck）已固化为 CI，
  外部贡献 PR 也会被机器把关
